## How to Update This File

When you cut a release:

1. Move relevant entries from `[Unreleased]` into a new version section, e.g. `## [1.1.0] - 2026-08-15`.
2. Group entries under `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, or `Security` — omit empty categories.
3. Keep `[Unreleased]` at the top for ongoing work.
4. If you tag releases on GitHub, consider adding compare links at the bottom, e.g.:
   ```
   [Unreleased]: https://github.com/Nitinx12/docker-environment-manager/compare/v1.0.0...HEAD
   [1.0.0]: https://github.com/Nitinx12/docker-environment-manager/releases/tag/v1.0.0
   ```
